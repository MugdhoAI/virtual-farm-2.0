page build plan, Figma documentation, or an old chatbot implementation. The

some real behavior exists but requirements remain; **NOT DONE** means the
requirement is not implemented; **BLOCKED** means an external source, product
decision, or unavailable reference is required; **OUT OF SCOPE** means the
provided PRD explicitly excludes it.
